# `black` was listed here from the beginning and had never been run. I9 called for adopting it;
# what was adopted instead is `ruff format`, and `black` is removed rather than left unused.
#
# Measured before deciding: on this tree, `ruff format` and `black` disagree on **35 of 195
# files** — under black 24.10, the version this file pinned, not just under 25.x. The whole
# disagreement is redundant parentheses around multi-line conditional expressions, which black
# adds and ruff does not. Neither output is better.
#
# So the choice is not about style, it is about how many formatters this repo has. Two that
# disagree on 35 files, with only one enforced in CI, is the same shape as the defects this
# project keeps finding: one fact stated in two places, where changing either has no effect.
# Whoever ran the unenforced one would produce a diff CI then rejected. `ruff format` wins on
# the tiebreakers — ruff is already a hard dependency, already blocking in CI, and already
# carries `line-length = 100` in `[tool.ruff]`, so the formatter and the linter cannot drift
# apart on line length the way a separate `[tool.black]` section could.

# `pip-audit` is deliberately NOT listed here, and that is not an oversight.
#
# It depends on `requests`, and installing `requests` into the environment the suite runs in
# changes yt-dlp's behaviour: yt-dlp prefers its `requests`-based request handler when the package
# is importable, and that handler leaves a socket unclosed. The resulting `ResourceWarning` is
# raised by the garbage collector at an arbitrary later moment, and because `filterwarnings = error`
# turns it into a failure, it lands on whichever test happens to be running. Measured: with
# `requests` present, 3-4 of the `tests/test_url_ingest.py` I13 tests fail non-deterministically
# under `pytest --cov`, and pass without it. Removing `requests` makes the same run green.
#
# So the audit runs in its own isolated environment in CI (see the "Audit Python dependencies"
# step in .github/workflows/ci.yml) rather than being installed alongside the tests. Auditing the
# dependency set must not alter the dependency set it is auditing.
